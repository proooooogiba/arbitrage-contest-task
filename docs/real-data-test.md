# Реальный спотовый тест

Тест использует SOLUSDT на Binance spot и Bybit spot.
Стратегия загружается в ZIP с `strategy.py`. Доступ выдаёт организатор.

## Публичный Train

Архив `train-SOLUSDT-spot-20261109.zip` находится в разделе **Files**.
[CodaBench](https://www.codabench.org/competitions/18505/).

В архив входят четыре Parquet за 29 сентября — 2 октября 2026 UTC,
`sources.json`, `config.json` и часовой пример `quickstart/events.jsonl`.

Начните с `quickstart/events.jsonl`, он готов к оценке.
Полный многодневный Train ещё не проверен полным запуском оценки.

```bash
python -m spot_contest validate --config examples/real-test-config.json \
  --data data/train/quickstart/events.jsonl
docker build -f Dockerfile.strategy -t spot-contest-strategy:real-test-20261109 .
python -m spot_contest evaluate --config examples/real-test-config.json \
  --data data/train/quickstart/events.jsonl --submission examples/baseline \
  --output runs/real-baseline-001 --image spot-contest-strategy:real-test-20261109
```

На сервере решения оцениваются на отдельном закрытом часовом наборе данных.

## Фиксированные правила теста

Для локального запуска используйте актуальный `examples/real-test-config.json`
из репозитория вместе с событиями публичного quickstart.

| Правило | Значение |
|---|---|
| Комиссия | 10 bps за каждое исполнение, в USDT |
| Дополнительная задержка рыночных данных | 8 мс |
| Отправка заявки | 8 мс |
| Доставка отчёта | 7 мс |
| Расчётное время обработки события | 2 мс на вызов метода стратегии |
| Доступная глубина | 5% объёма на каждом ценовом уровне с вычетом исполнений |
| Максимальный возраст стакана | 500 мс с учётом возраста источника |
| Капитал | По 25 000 USDT и 210,26 SOL на биржу |
| Опорная цена | 118,8950 USDT из начальных публичных Train-кадров |
| Стартовый номинал | 99 997,7254 USDT |

Например, при объёме уровня 100 SOL стратегия может исполнить на нём суммарно
до 5 SOL. Повторный срез с тем же объёмом не восстанавливает использованный лимит.
Правила его пополнения — в [описании ликвидности](architecture.md#балансы-и-ликвидность).

История стаканов представлена срезами раз в 100 мс.
Задержки отсчитываются от доступности среза.

Параметры модели заданы в `config.json`, одинаковом для Train и закрытого теста.

В конце исходный запас SOL восстанавливается отдельно на каждой бирже по
оставшейся глубине с taker-комиссией. Стратегия без сделок получает ноль.

Включён обязательный парный вход. Отправляйте Buy и Sell одинакового объёма
на разных биржах. Остаток от независимого исполнения ног нужно закрыть за
2 секунды. [Правила парного входа](strategy-contract.md#обязательный-парный-вход).

## Стратегии для проверки

- `examples/hold` — стратегия без сделок с нулевым результатом.
- `examples/baseline` — арбитраж с учётом комиссий.
- `examples/cross_spread` — арбитраж положительного спреда без учёта комиссий в сигнале.
- `examples/broken` — ошибка, приводящая к `Failed` без score.

Оба торговых примера не реализуют полноценное аварийное хеджирование.
Нулевая или отрицательная доходность не считается технической ошибкой.

Параметры реального теста отличаются от синтетического примера, поэтому их
результаты не сопоставимы напрямую.
